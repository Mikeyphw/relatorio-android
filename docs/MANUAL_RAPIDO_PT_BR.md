# Manual rápido — Relatório Mensal AD 1.0

O aplicativo foi feito para funcionar como um formulário guiado. Ele salva as alterações automaticamente e não precisa de internet.

## 1. Criar o relatório

```text
RELATÓRIO MENSAL AD

[ PREENCHER NOVO RELATÓRIO ]
```

O **Relatório AD Timóteo** já aparece marcado. Use **Relatório Completo** somente quando precisar do formulário anterior.

## 2. Conferir os dados da igreja

Escolha o mês e confira:

- regional;
- congregação;
- pastor dirigente;
- ministério;
- pastor presidente.

Toque em **Salvar e continuar**.

## 3. Preencher os números

```text
Pastores

[ − ]       2       [ + ]
```

Use os botões de menos e mais. Também é possível tocar no número e digitar. O aplicativo não aceita números negativos.

## 4. Registrar movimentações

Toque em **Adicionar pessoa**, informe o nome e escolha o motivo por extenso. O código, como `BNA` ou `CMR`, é preenchido automaticamente.

## 5. Revisar e concluir

Na revisão:

- avisos amarelos pedem conferência;
- erros vermelhos precisam ser corrigidos;
- quando estiver tudo certo, toque em **Concluir relatório**.

## 6. PDF

No relatório concluído, use:

```text
[ VISUALIZAR PDF ]
[ SALVAR UMA CÓPIA ]
[ IMPRIMIR ]
[ COMPARTILHAR PDF ]
```

## 7. Guardar um backup

Na tela inicial, toque em **Backup e restauração**.

- **Salvar backup dos dados** cria um arquivo pequeno para restauração.
- **Salvar pacote com PDFs** cria um ZIP com o backup e os PDFs concluídos.

Guarde o arquivo em local seguro antes de trocar de aparelho ou reinstalar o aplicativo.

## 8. Restaurar em outro aparelho

1. Abra **Backup e restauração**.
2. Toque em **Escolher arquivo de backup**.
3. Confira a prévia.
4. Autorize a substituição do rascunho somente quando desejar.
5. Toque em **Restaurar agora**.

Relatórios repetidos são ignorados. O arquivo é verificado antes de qualquer alteração no banco.
